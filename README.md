# Ink Bloom

A tiny single-file canvas toy: click or drag on the screen to spawn glowing ink "blooms" that drift and fade, leaving soft trails behind.

## Usage

Open `index.html` in any modern browser — no build step or dependencies required.

- **Click or drag** on the canvas to bloom ink.
- **Swatches** (top right) pick the bloom color.
- **🎨** cycles through color palettes.
- **Clear** wipes the canvas.
- **Save PNG** downloads the current canvas as an image.
